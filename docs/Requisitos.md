# Requisitos do Projeto Wins Streak Control

## Problema

Para a realização de uma Win Streak, os participantes desse desafio geralmente registram seus progressos em overlays de suas lives ou em um arquivo txt, não possuíndo uma forma segura de registrar o andamento do seu desafio, e também permitindo que outras pessoas possam .

## Público Alvo

Participantes do desafio de Win Streak.

## Requisitos Funcionais

1. O sistema deve permitir que cada usário possa realizar cadastro, login, edição e exclusão de seu perfil.
2. O sistema deve permitir registrar e atualizar as informações de nome, email, senha e descrição.
3. O sistema deve permitir que cada usuário possa criar, atualizar e excluir um ou mais registros do desafios.
4. O sistema deve permitir registrar e atualizar as informações do desafio, como descrição, número de partidas ganhas e evidência.
5. O sistema deve permitir que para cada registro de número de partida, toda vez que for atualizada o registro deve ter uma evidência, como um link do youtube, twitch e kick.
6. O sistema deve permitir que outros usuários possam ver o andamento de outra Win Streak.
7. O sistema deve permitir que outros usários possam ser adicionados como participantes do registro de uma Win Streak.
8. O sistema deve permitir que usuários possam comentar na Win Streak de outras pessoas.
9. O sistema deve permitir que curadores possam avaliar as Wins Streaks.
10. O sistema deve permitir que os curadores possam banir usuarios.
11. O sistema deve permitir que um usuario possa denunciar outros usuarios.
12. O sistema deve permitir que o usuario pesquise por outros usuarios.
13. O sistema deve permitir que o usuario possa pesquisar por Wins Streaks.
